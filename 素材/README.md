# 素材

把图丢进对应的文件夹就能用，**不需要改任何变量或代码** —— 变量里存的是文件名，
界面取图时会自动拼成 `素材源/<类别>/<文件名>.png`（前缀在
`src/修仙恋爱角色卡脚本/schema.ts` 的 `素材源` 一行，换仓库时只改那一行）。

## 放什么

```
素材/
├─ 立绘/          900×1200（3:4 竖版）为宜，界面会按 object-fit: cover 裁切，脸放偏上
│  ├─ 主角.png
│  ├─ 苏挽烟.png   顾清漪.png   云见月.png   谢知微.png   姜雪辞.png
│  └─ 温若.png     白蘅.png     裴小满.png   楚青鸾.png   柳眠.png
├─ 背景/          1920×1080 横版，铺满中栏
│  ├─ 青冥山脉.png  云梦泽.png    北荒雪原.png
│  └─ 南疆瘴林.png  中州城.png    东海之滨.png
└─ CG/            事件画，比例随意（界面按 contain 显示，不会被裁）
   └─ 想画哪个场面就放哪张，然后在变量更新规则里把可用名字列给 AI
```

**命名规则：立绘用姓名、背景用大区名**，和变量里的键一字不差。
名字对不上就是 404 —— 界面会退回水墨占位，不会崩，但也看不到图。

另外卡头像不在这里：它是 `src/修仙恋爱角色卡脚本/头像.png`，
打包时会被封进导出文件的 `chara` 数据块，那张图就是你要发给别人的角色卡。

## 少了图会怎样

| 缺什么 | 结果 |
|---|---|
| 某些女主立绘 | 那位显示水墨占位（一个大字 + 姓名），其余照常 |
| 全部背景 | 舞台退回样式里那几重远山 |
| 某张大区背景 | 走到那个大区时退回远山 |
| 主角立绘 | 主角那格显示水墨占位 |
| 某个 CG | 那张 CG 不出现，其余照常 |
| 卡头像 | **导出的文件不是合法 PNG，别人导入不了** —— 这个不能缺 |

## 图从哪来

放进这个仓库、走 jsdelivr 就行（`素材源` 那个地址）。好处是**别人 fork 你的卡时图也跟着走**，
他不需要另外准备素材。想换图床就把 `素材源` 改一行，或者干脆在变量里填完整网址
（`素材链接` 遇到 `http` 开头的值会原样使用）。
